Fanbox

constructor(guestManifestUrl: String, guestTrustedKeys: Map<String, ByteArray>, guestCache: FanboxGuestCache, guestEventListener: (FanboxGuestEvent) -> Unit = {}, logLevel: FanboxLogLevel = FanboxLogLevel.NONE, ioDispatcher: CoroutineDispatcher = Dispatchers.IO, cookieStorage: FanboxCookieStorage = InMemoryFanboxCookieStorage(), tokenStore: FanboxTokenStore = InMemoryFanboxTokenStore())

Builds FANBOX requests and interprets their responses with the signed Zipline guest.

The guest loads in the background from guestManifestUrl once this instance is created, and modules already in guestCache are not downloaded again. When the manifest cannot be loaded from guestManifestUrl, the guest last verified into guestCache is loaded instead. Requests wait for the load. When neither loads, every request of this instance fails with FanboxException.GuestFailure.

guestTrustedKeys maps each trusted signing key name to its Ed25519 public key. A manifest signed by any of them is accepted.

guestEventListener receives what happens on the guest path. It is called on a background thread, possibly before this constructor returns and possibly from several threads at once, so it must return quickly and must not call close. An exception it throws is logged rather than propagated.
