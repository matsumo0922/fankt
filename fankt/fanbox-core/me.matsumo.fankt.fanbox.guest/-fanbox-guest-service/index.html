FanboxGuestService

interface FanboxGuestService

Builds FANBOX requests and interprets FANBOX responses inside the Zipline guest, so that a parsing fix reaches users by replacing the guest bundle rather than by shipping a new app.

No parameter carries a credential. The host attaches cookies and the CSRF token after it validates the descriptor this service returns. The guest sees the CSRF token only in the homepage it parses, which parseHomepage returns for the host to store; it never sees a cookie. Functions that interpret no response body, such as those for liking or commenting, only build the request.
